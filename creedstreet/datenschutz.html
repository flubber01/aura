Verantwortlicher & Hosting

Rechtlicher Anbieter, Datenschutzkontakt, Hostinganbieter, Rechtsgrundlagen, Empfänger und Speicherdauern müssen vor dem öffentlichen Betrieb konkretisiert werden. Technische Zugriffsdaten wie IP-Adresse, Zeitpunkt und angeforderte Datei können beim Hosting verarbeitet werden.

Projektbriefing

Formulareingaben werden nicht an einen Server gesendet. Beim Download entsteht eine Textdatei auf deinem Gerät. Der Inhalt wird nicht in einem Kundenkonto oder einer Datenbank gespeichert.

FAQ-Chat

Der Studio-Guide arbeitet regelbasiert in deinem Browser. Nachrichten werden nicht an einen KI-Anbieter gesendet und nicht dauerhaft gespeichert. Bitte gib keine vertraulichen Daten ein.

Social Fast Connect & lokale Einstellungen

Wenn du eine öffentliche Profil-URL selbst hinterlegst, wird sie im lokalen Browserspeicher unter cs47-social-v1 gespeichert. Das erfolgt erst nach deinem ausdrücklichen Speicherklick. Du kannst die Links über „Lokale Links löschen“ oder die Browserfunktionen entfernen. Gespeichert werden nur öffentliche URLs, keine Passwörter oder Zugriffstokens. Es gibt keine automatische Anmeldung.

Suno-Profil

Das Profil https://suno.com/@creedstreetstudios47 ist im Sound-Bereich und im Social-Schnellzugriff verlinkt. Es ist kein eingebetteter Suno-Stream. Suno wird erst durch deinen Klick in einem neuen Tab geöffnet; beim Laden dieser Website erfolgt keine Anfrage an Suno.

Externe Links & Teilen

Externe Social-Dienste werden erst durch deinen Klick auf einen Profil-Link geöffnet. Dabei gelten die Datenschutzinformationen des jeweiligen Anbieters. Die Teilen-Funktion nutzt den nativen Browserdialog oder kopiert den aktuellen Link nach deiner Aktion.

Audio & Medien

Die vom Betreiber bereitgestellte Datei „Schwarzes Eisen.mp3“ wird vom gleichen Server als Hintergrundmusik geladen. Die Website versucht hörbare Wiedergabe beim Öffnen; Browser können das blockieren. Über „Sound an/aus“ steuerst du die Musik jederzeit. Nach einer ausdrücklichen Sound-Auswahl werden die Einstellung und Abspielposition im Sitzungsspeicher unter cs47-sound-v1 für Seitenwechsel gespeichert. Es gibt keinen Musikdienst-Aufruf und keine Suno-Einbettung; der Suno-Profillink öffnet weiterhin nur nach Klick einen neuen Tab. Bilder und Schriftdateien werden ebenfalls vom gleichen Server geladen.

Der Werbebereich ist derzeit ein Platzhalter. Es werden keine Google-AdSense-Skripte geladen, keine Anzeigen angefordert und keine Werbe-Cookies gesetzt. Eine Aktivierung benötigt unter anderem passende Kontofreigaben, eine konkrete Datenschutzerklärung und eine geeignete Einwilligungslösung.
